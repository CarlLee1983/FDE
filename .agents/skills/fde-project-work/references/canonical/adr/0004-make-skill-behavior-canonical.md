# Make skill behavior canonical

Project language is governed by `CONTEXT.md`, hard-to-reverse decisions by accepted ADRs, and runtime analysis behavior by the skill's `SKILL.md`; `README.md` is the entry point. Capability plans, methods, enterprise architecture, research, and cases support those sources but do not independently expand the project's capability boundary. Canonical files and the skill should be corrected with the smallest coherent changes; existing examples remain supporting evidence instead of being deleted or treated as the roadmap.

**Falsified if:** a file other than `CONTEXT.md`, `docs/adr/`, `.agents/skills/fde-project-work/SKILL.md`, or `README.md` is cited as the source of a rule, or a canonical file defers to a supporting document for its boundary.

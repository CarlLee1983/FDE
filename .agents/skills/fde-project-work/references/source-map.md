# Source map

`CONTEXT.md` governs project language, accepted ADRs govern hard-to-reverse decisions, and `SKILL.md` governs analysis behavior. The files below provide supporting detail and cannot independently expand that boundary. Resolve paths from the repository root and read only the source needed by the active branch.

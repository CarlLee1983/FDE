# Separate analysis completion from assurance

A case analysis is complete when it gives the user a bounded diagnosis, redesigned workflow, justified intervention choice, explicit evidence limits, and accountable next action. G1–G6 and other assurance gates are activated only when a recommendation depends on real access, release, increased authority, persistent action, or a value claim; they restrict what may be claimed or done and are not the default measure of analytical progress.

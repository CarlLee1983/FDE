# Use an adaptive analysis core

Every case follows the small core of framing the operating problem, diagnosing and redesigning the workflow, selecting the simplest sufficient intervention, and forming an operating solution. The six-stage method, gates, schemas, and executable validation are optional depth mechanisms rather than mandatory outputs; AI is assessed only as one intervention among process change, responsibility change, data repair, deterministic software, and human judgment. Generic cases may use clearly labelled reference hypotheses with a stated validation path, but they cannot claim target-enterprise facts or outcomes.

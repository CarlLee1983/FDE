# 案件 D：新政策證據調節說明

## 結論

新證據 `SG-FIN-POL-2025-04` v2.0 只在「新加坡 Home Appliance 商品線退款核准」這個範圍內取代舊規則 R2，因此我只重算了 C2 一條結論，其餘 C1、C3、C4 與 U1、U2 原樣保留；另外因新規則多了兩項狀態條件，新增 U3、U4 兩項未決事項。已就地更新 `docs/evaluations/evidence/2026-09-09-new-evidence-reconciliation/case-D/after/case-record.md`，未新增或修改任何其他 repo 檔案。

## 界定新資訊

來源 `SG-FIN-POL-2025-04`，版本 v2.0，生效日 2025-04-01，權責為新加坡財務政策負責人，適用範圍文件本身明示「僅限新加坡 Home Appliance 商品線」，且只取代 `SG-FIN-POL-2024-11` 中該商品線的退款核准條款。這幾項界定是後面判斷相依性的全部依據。

## 關係分類與相依性測試

對 R2 是 `supersedes`：同一市場、同一商品線、同一權責層級，較新文件明示取代。對 R1（台灣）、R3（新加坡 Travel Accessories）、P1（唯讀查詢流程）是 `coexists`——不同範圍且與新證據無事實或規則上的相依，因此不重算。R3 尤其明確：新文件自己說其他商品線不受影響。

## 變更了什麼

R2 保留全文但標記為已被取代、僅供追溯，證據狀態註明「截至 2025-03-31 為現行」。新增 R4 記錄現行規則：SGD 500 門檻，加上「帳號無未結爭議」與「該客戶 90 天內自動放行次數未達 3 次」兩項條件。C2 重算為現行版，同時把前版 C2 與其依據原文保留在下方，並說明「AI 適配判斷未變、變動的是門檻值與兩項狀態條件」——三項判準仍是穩定可計算的規則，屬確定性軟體，不是 AI 題目。另加一節「新證據調節記錄」，把界定、關係分類、重算清單與保留清單寫在案件記錄裡，讓改動理由與改動同處一地。

## 保留了什麼、為什麼

C1 依據 R1，台灣市場，新證據範圍不觸及。C3 依據 R3，新證據明示不影響其他商品線。C4 依據 P1，唯讀查詢與核准規則無相依。U1（台灣是否分層門檻）維持 `missing`：新加坡調高門檻是另一個範圍的事實，是脈絡而不是重算理由，更不是 U1 的答案；跨市場門檻比較可以當作選項提出，但我沒有把它變成本案的工作項目或新的待決決策。U2 完全未動。

## 仍未決

U3（新增）：兩項新條件是否有可查的權威資料來源——「未結爭議」的判定來源與定義、90 天自動放行次數的計數來源與起算基準／時區。狀態 `missing`，須由持有退款／爭議系統的角色提供欄位與資料字典，非本案可自行查證。若任一來源不可得，該商品線的自動放行不可安全執行，需暫維人工批准；這只影響 C2 的可執行性。

U4（新增）：政策是否已落地為營運系統的現行設定，狀態 `missing`。政策文件證明政策，不證明系統已照此執行；系統做得到某件事也不等於被授權這麼做。維運權責的具體角色標為 `missing`，未擅自指名。

## 可續行與須等待

不依賴 R4 的工作可以繼續：C4 的退款進度查詢資訊整合分析，以及 R4 三項判準的規則邏輯與放行紀錄欄位設計。須等待 U3、U4 回覆的是新加坡 Home Appliance 自動放行的實作與上線。

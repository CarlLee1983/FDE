# 供應商發票例外處理參考請求

為應付帳款團隊建立一個通用的 FDE 案例：供應商發票因採購單、收貨紀錄或發票資料不一致，導致專員跨 ERP、Email 與試算表反覆查核、案件狀態分散、例外沒有明確責任人與回覆期限。

案例必須先重新設計例外分類、責任歸屬與案件狀態，再以確定性規則支援三方核對與重複發票檢查；生成式 AI 只保留給非標準文件擷取與溝通摘要，且不得核准付款、改寫政策門檻或變更供應商銀行資料。第一階段只能是唯讀重播，不寫回 ERP、不影響付款。

本 repository 請求只建立 `proposed` 的參考形狀。實際企業、流程負責人、現行 SOP、去識別化案件、基線、目標與接受紀錄均為 `missing` 或 `unverifiable`。
